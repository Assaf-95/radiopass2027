Gz slice selection: Gz during RF excites one slice; a small opposite lobe refocuses phase from the slice gradient.
Gy phase encoding: Gy amplitude changes each TR to fill different ky lines. More phase steps increase scan time: total time is approximately TR multiplied by number of phase lines.
Gx readout: Frequency encoding is along X during sampling. Chemical shift creates a fat-water frequency difference, producing displacement along the frequency encode direction.
90° pulse tips longitudinal magnetization into the transverse plane, creating transverse signal. 180° pulse reverses phase dispersion so spins rephase and an echo forms.
