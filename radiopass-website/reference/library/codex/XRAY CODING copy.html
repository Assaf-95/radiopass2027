2nd Interactive Radiographic Magnification Simulator for FRCR Physics

Drag the object between source and detector to see real-time magnification, projected image size, and focal-spot-driven geometric unsharpness.

Source, object, and detector are center-aligned and parallel on the same geometric plane. Dark-red dotted rays and shading show penumbra boundaries and the full blur region at the detector surface. Grey lines mark SID, SOD, and ODD.

Key points

  • Red dotted rays start from both focal-spot edges and show penumbra boundaries.
  • Red shaded band on detector = blurred region (geometric unsharpness, Ug).
  • Dark central band on detector = sharp image core.
  • Penumbra is caused by the finite focal spot size (not an ideal point source): multiple point sources within the focal spot create overlapping edge shadows at object margins (represented as xxx in our diagram); as focal spot size increases, penumbra increases and edges become less sharp; if the focal spot were an ideal point source, there would be no penumbra and edges would be perfectly sharp.
  • Notice how increasing ODD leads to increased magnification and increased geometric unsharpness.
  • Notice how increasing SID (while keeping SOD constant) increases magnification and increases geometric unsharpness because ODD (SID - SOD) increases.
  • Observe dynamically in the diagram: decreasing SOD -> magnification up -> penumbra up; increasing focal spot size -> penumbra up; increasing ODD -> penumbra up.
