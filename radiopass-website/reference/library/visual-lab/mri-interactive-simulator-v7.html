MRI Interactive Simulator: Version 7

Build a pulse sequence step-by-step, then watch Bloch dynamics, spatial phase behavior, signal formation, and k-space traversal update in real time.

How to use

  1. Choose line count (16, 32, or 64).
  2. Set sequence controls (flip, RF duration, gradients, TE, TR).
  3. Click Acquire Next Line to run one TR and fill one new k-space line.
  4. Repeat until Lines acquired = N/N.

k-space is manual in Version 7: it does not auto-fill.
