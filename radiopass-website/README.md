# RadioPass — FRCR Part 1 Physics Website

A complete responsive React + TypeScript website for RadioPass, an FRCR Part 1 Physics question bank and interactive visual teaching platform.

## Included pages

- Conversion-focused homepage
- Question bank
- Interactive visual lab
- Six-week study plan
- Pricing
- Login
- About, privacy, terms and 404 pages

## Interactive elements

- CT dose/noise simulation
- Sample question with answer feedback
- Topic filtering
- Pricing billing toggle
- FAQ accordion
- Responsive navigation

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The pricing values and product counts are editable placeholders in `src/App.tsx`. Replace the pre-launch legal copy before accepting customers.
